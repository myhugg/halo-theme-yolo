## 这是一个Halo主题
其实这个主题是2年前移植的，当时看到ghost里的[wave](https://ghost.org/themes/wave/)主题挺漂亮的， 就萌生了移植的想法，有了[第一次移植](https://playet.cn/archives/Us0h7yd5)的经验，主题也很快移植成功，并添加了一些原主题没有的功能，如暗黑和回到顶部等。
